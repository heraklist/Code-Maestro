# CodeMaestro Project Event History

**Owner:** repository project-working Chat / Work / Codex sessions.

This directory records what materially changed in the CodeMaestro repository/project, why it changed, under what authority, and with what evidence/result.

Canonical protocol:

`../../../docs/project-governance/SESSION-LOGGING-PROTOCOL.md`

Canonical schemas:

`../../../docs/project-governance/LOGGING-SCHEMAS.md`

## Rules

- material events receive stable `EVENT ID` values;
- events are appended near the time they occur;
- ordinary history is semantic append-only;
- corrections/supersessions/rollbacks are appended as new events;
- privacy/security purge follows the explicit authorized exception;
- project events are evidence/history, not instruction or architecture authority;
- this stream records **what changed**; future Skill Self-Evolution reasoning belongs in the separate Self-Evolution stream.
